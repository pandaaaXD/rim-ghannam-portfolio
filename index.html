PROJET INFRA Groupe CEGI · alternance

NOC — supervision centralisée Grafana (PRTG · ELK · Loki)

Conception & maintenance du NOC — dashboards, chaînes de données, scripts

Construction d'un NOC restitué dans Grafana et affiché sur mur TV en mode kiosk, pour superviser un parc hébergé multi-clients. Trois chaînes de données indépendantes y convergent : les métriques infra PRTG (CPU / RAM / disque par serveur et par rôle), la disponibilité applicative synthétique mesurée par des scripts Bash qui poussent vers Loki, et les logs IIS / applicatifs remontés par la stack ELK (Filebeat → Logstash → Elasticsearch).

  • Mur TV NOC : dashboards Grafana 12 en mode kiosk, rotation par playlist — l'état du parc se lit en un coup d'œil
  • Trois chaînes fédérées : PRTG exposé à Grafana via un proxy Nginx (filtrage par client), checks Bash → Loki, logs via ELK
  • Contrainte respectée : pipeline de logs intouchable → enrichissement par runtime fields dans les index templates Elasticsearch, qui survivent aux rollovers ILM
  • Parc multi-clients : serveurs classés par conventions de nommage (type d'infra × rôle) qui alimentent des dashboards templatisés

# deploy_base.yml — configuration de base des serveurs Debian
- hosts: serveurs_debian
  become: true
  tasks:
    - name: Mettre à jour le cache APT
      ansible.builtin.apt:
        update_cache: yes

    - name: Déployer la configuration SSH durcie
      ansible.builtin.template:
        src: sshd_config.j2
        dest: /etc/ssh/sshd_config
      notify: redemarrer sshd

  handlers:
    - name: redemarrer sshd
      ansible.builtin.service:
        name: ssh
        state: restarted
